# 权限上下文冻结（v1）

每个已认证请求解析为：`user_id`、`role`、可选 `teacher_id`、可选 `student_id`、`permissions`、`course_ids`、`class_ids`。课程和班级范围在服务端每次请求解析，不能只依赖前端或把全量范围永久塞入令牌。

教师只能访问本人课程、班级和班内学生；学生只能访问自己的课程、签到、作业、实验、日志和成绩；管理员的基础设施高风险操作必须写入审计。前端角色切换仅为验收展示，生产环境不得允许普通用户切换身份。

`20260922_0018`（身份权威增量迁移）登记并按最小可用范围授予以下交互权限；可信身份解析只从 `auth_role_permission`（角色权限关联）得出权限，绝不把浏览器请求头拼入结果。

| 角色 | 已授予的业务范围 |
| --- | --- |
| 管理员 | 账号档案和历史身份核对、全局课程资源治理、运行恢复与基础设施、跨课程成绩与归档、审计查阅；高风险操作仍由各服务写入审计。 |
| 教师 | 本人课程/班级与名单、资源审核和冻结、实验定义与发布、课堂运行协助/日志、本人课程成绩/学情/归档和审计查阅。所有操作仍同时检查课程、班级及任课范围。 |
| 学生 | 本人课程学习、已发布资源、本人实验启动/查看/提交/终端、获准日志任务、本人成绩和学情。所有操作仍同时检查学生档案、名单、课程和班级范围。 |

`integration:dispatch`（集成事件派发）、`grading:consume`（评分事件消费）、`audit:ingest`（审计事件写入）和 `classroom.events.consume`（课堂事件消费）只登记给受控内部服务身份；它们不得通过管理员、教师或学生角色授予。下游服务仅接收课堂服务针对已获准业务操作缩减后的权限集合，不能把普通账号扩展为内部服务身份。

`grading.score.proof.frozen`（评分证明已冻结）不是普通账号可调用的写入能力：它只能由 A 的固定服务身份 `service_teaching_score_prover` 随受控事务事件箱写入，再被 `integration:dispatch`（集成事件派发）投递，并由具备 `grading:consume`（评分事件消费）的内部服务持久化。教师、学生和管理员均不能通过请求头、成绩接口或任意 `source_proof`（来源证明）摘要创建该事实。

身份提供方式按环境强制隔离，默认关闭开发身份头。只有同时设置 `YUEKE_ENV=development`（开发）或 `YUEKE_ENV=test`（测试）以及 `YUEKE_ALLOW_DEV_IDENTITY_HEADERS=1` 时，才可使用 `X-User-Id` 等请求头进行本地契约验收；任何缺失、其他环境或 `production`（生产）都无条件拒绝这些请求头。生产只接受上游受信任中间件写入的主体，平台通过可替换的 `TrustedIdentityResolver`（可信身份解析器）按 `user_id` 或外部主体标识重新查询本库的有效账号、角色、权限、教师/学生档案和课程/班级范围。仓库不实现或部署登录、密钥或单点登录方案。生产尚未接入认证中间件时返回 `AUTH.TRUSTED_IDENTITY_REQUIRED`，不得降级为可伪造请求头。

管理员可创建和查询不含密码或认证凭据的最小账号档案。学生名单按 `student_profile.student_number` 解析已有、启用的档案，服务端写入该档案的全局 `student_id`；未知学号、停用档案、姓名不一致和历史标识差异均进入逐行错误或 `identity_reconciliation_case`（身份核对事项），不得按班级生成学生身份或静默覆盖历史名单。

教师学生管理接口必须同时校验教师身份、任课关系与 `class_ids` 数据范围。教师可以加入已有学生账号或解除本人班级的 `class_membership`，但不能查看全校学生、删除全局账号、修改角色或操作其他教师的班级。学生角色不得访问任何教师学生管理接口。

服务层使用 `UserContext` 进行权限和数据范围判断，禁止分散的角色字符串判断。所有拒绝均返回标准错误信封，且不泄露其他用户或资源是否存在。

E 向学生分发 D 所属日志制品时不得放宽 D 的普通实例所有权规则。E 只有在确认 `student_log_assignment`、课程、班级、实验发布和精确引用集合后，才能使用 `YUEKE_LOG_DISTRIBUTION_SIGNING_KEY` 签发最长 60 秒的分发授权；D 必须重新验证签名、有效期、学生身份、课程/班级范围以及每个 D 源事实。D 再使用独立的 `YUEKE_ARTIFACT_STORAGE_SIGNING_KEY` 签发存储能力，E 不得持有该密钥。两把密钥均至少 32 字节，只能由环境密钥注入；缺失或过短时必须安全失败，禁止写入源码、日志或下载地址。
