异常恢复

实例或节点失败时，优先保留学生成绩、实验记录和审计证据，再重新创建运行环境。

实例启动失败

自动在同节点重试 1 次；仍失败则换节点重新创建。保留原 instance request 与失败日志。

节点离线

节点自动摘除，不再接新任务；未完成学生实例进入恢复队列，在其他节点重建。

高 CPU / 高内存

先按资源限额限制，若持续异常则冻结必要日志并允许教师或管理员重建实例。

判分服务异常

学生操作结果先入队，恢复后补判；不因评分服务短暂不可用丢失实验进度。

镜像拉取失败

优先调度到已有镜像缓存节点；必要时重新拉取并校验摘要。

实验超时

先保存得分、日志和提交状态，再销毁容器与网络，避免资源长期泄漏。
