## SEED Labs 的处理规则

SEED Labs 当前 `LICENSE.md` 明确：所有 SEED labs 与关联材料使用 CC BY-NC-SA 4.0，并明确 Translation 属于 derivative work。

因此：

- 不把 SEED 原文直接复制进跃科商业课程库；
- 不把 SEED 教材逐段翻译后作为跃科商业交付物；
- 可以读取其公开分类、知识域与课程覆盖，用于课程体系 gap analysis；
- 对相同知识点重新编写中文讲义、题目、实验目标、实验步骤、判分逻辑和图示；
- 原创内容必须能够独立追溯到跃科自己的版本、作者、审核和验收证据。

## Vulhub 接入规则

Vulhub 只作为外部靶场来源。第一阶段适配器只读取元数据，不自动运行 Docker。

任何第三方 Compose 在进入 D 线之前必须拒绝：

- privileged
- host network
- host PID / host IPC
- docker.sock
- 宿主绝对路径挂载
- 未批准 capability
- 直接设备映射

最终必须转换为跃科 `LabDefinition`，固定 image digest，经 Node Agent 在隔离网络运行。
